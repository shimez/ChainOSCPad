# ChainOSCPad v1.1.1

v1.1.1は、v1.1.0リリース後の実使用レビューを反映したWebUI refinementのPATCHリリースです。

## 変更内容

- Device Card Headerを`[#N Type]`表記へ変更
- 中間的なデスクトップ幅でEncoder PushのOSC Message Editorがはみ出す問題を修正
- Press/ReleaseとSequenceの切替時にKey Mode欄の配置がずれる問題を修正

Device Preset、Migration、Validationのsemanticsおよび保存設定形式に変更はありません。
