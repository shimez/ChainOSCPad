ChainOSCPad

XIAO ESP32S3／ESP32C3／ESP32C5／ESP32C6へファームウェアをブラウザーからインストールできます。

Stable version 1.0.2

ChainOSCPadは個人が開発する非公式プロジェクトです。Seeed Studioその他のハードウェアメーカーによる公式製品ではありません。

Web Installer

XIAOをデータ通信対応USBケーブルでPCへ接続し、下のボタンからシリアルポートを選択してください。接続したS3／C3／C5／C6に合うファームウェアが自動的に選択されます。

このブラウザーはWeb Serialに対応していません。デスクトップ版ChromeまたはEdgeを使用してください。
  1. XIAOをデータ通信対応のUSBケーブルで接続します。
  2. 「Install ChainOSCPad」を押し、XIAOのシリアルポートを選びます。
  3. 画面の案内に従ってインストールを完了します。
ポートが表示されない場合は、XIAOのBOOTボタンを押しながらUSBへ接続し、ダウンロードモードを試してください。
再インストールや消去を行う前に、必要な設定をWeb UIの「設定をエクスポート（JSON）」でバックアップしてください。

Quick Installation Guide (English)

Use desktop Google Chrome or Microsoft Edge. The correct ESP32S3, ESP32C3, ESP32C5 or ESP32C6 firmware is selected automatically.

  1. Connect the XIAO with a USB cable that supports data.
  2. Select Install ChainOSCPad and choose the XIAO serial port.
  3. Follow the on-screen instructions to complete the installation.
If the port is not listed, hold the XIAO BOOT button while reconnecting the USB cable.
Before reinstalling or erasing the device, back up important settings with Export Settings (JSON) in the Web UI.
